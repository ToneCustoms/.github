# ToneCustoms Support

ToneCustoms provides customer assistance for its FiveM resources through its official channels.

## Where to go

| Request | Official channel |
| --- | --- |
| Installation, configuration, and product questions | [ToneCustoms Discord](https://discord.gg/JdZ7NTG5KF) |
| Product guides, compatibility, and updates | [ToneCustoms Documentation](https://tonecustoms.github.io/tonecustoms-docs/) |
| Documentation errors or suggestions | [Documentation Issues](https://github.com/ToneCustoms/tonecustoms-docs/issues/new/choose) |
| Product listings and purchases | [ToneCustoms Tebex Store](https://tonecustoms.tebex.store/) |
| Billing disputes or existing buyer-support cases | The original Tebex order or support thread |
| Confidential security concerns | [Security Reporting](SECURITY.md) |

When asking for technical help, provide the resource name, relevant framework and dependency versions, expected and actual behavior, and redacted logs where useful.

Never share credentials, API tokens, private license keys, customer data, or sensitive vulnerability details in public posts.

Support is available through the official channels; this document does not guarantee specific response or resolution times.
