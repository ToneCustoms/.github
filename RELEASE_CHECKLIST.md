# ToneCustoms — Product Release Checklist

Use this checklist when preparing a **specific, owner-approved** FiveM resource for publication. It is a workflow standard, not evidence that any project has already passed.

## 1. Product readiness

- [ ] Confirm the exact resource name and approved scope.
- [ ] Verify gameplay, user interactions, dependencies and relevant frameworks.
- [ ] Confirm installation, configuration and required inventory items.
- [ ] Resolve blocking defects and document any remaining known limitations.
- [ ] Ensure resource files do not contain credentials, bot tokens, webhooks or customer information.
- [ ] Review rights to any third-party assets and dependencies.

## 2. Package quality

- [ ] Include only the approved resource and required install documentation.
- [ ] Ensure file and folder names match the documented installation instructions.
- [ ] Validate manifests, configuration syntax and any SQL or item-definition snippets.
- [ ] Keep development archives, unrelated work files and private internal notes out of customer packages.
- [ ] Check the delivered package against the approved working build.

## 3. Business and customer information

- [ ] Confirm the actual approved version and publication date.
- [ ] Update the public product page, compatibility notes and installation guide.
- [ ] Record meaningful release notes; never fabricate a version or date.
- [ ] Confirm the current Tebex listing, price and checkout terms.
- [ ] Confirm support destination and any upgrade instructions.
- [ ] Verify that demo media accurately reflects the delivered functionality.

## 4. Approval and publication

- [ ] Founder/owner approves the final build and customer-facing claims.
- [ ] Publish only to authorized distribution channels.
- [ ] Keep private source and paid assets restricted.
- [ ] Record the published version and any follow-up issues in the existing project workflow.

**Important:** A commit, demo, repository milestone or test result does not automatically authorize a public or paid release.
