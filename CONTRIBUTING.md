# ToneCustoms Contribution Standards

ToneCustoms is an independent FiveM development business. This document provides default guidance for organization repositories that do not define their own contribution instructions.

## Before proposing a change

- Use the repository's existing issue and pull request templates when available.
- Identify the affected resource, environment, and expected behavior.
- Keep changes focused and preserve approved gameplay and configuration.
- Verify dependencies and customer-facing claims before updating documentation.
- Do not publish private resource files, credentials, webhook tokens, license keys, or customer data.
- Do not assume a merge or commit constitutes a release; versioning and distribution require owner approval.

## Support and security

Use [ToneCustoms Discord](https://discord.gg/JdZ7NTG5KF) for general product support. Report sensitive vulnerabilities privately following [SECURITY.md](SECURITY.md).
