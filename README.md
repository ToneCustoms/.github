This repository maintains the official [ToneCustoms GitHub organization homepage](https://github.com/ToneCustoms).

The public organization profile is defined in [`profile/README.md`](profile/README.md). This repository is for business presentation and community-facing links; individual FiveM resources are maintained in their own repositories.

## Maintenance guidelines

- Keep product descriptions accurate and distinguish active development from published releases.
- Link customers to official documentation and current store listings.
- Do not commit private resource files, license keys, tokens, credentials, or customer information to public repositories.
- Maintain both the organization and founder profiles without assuming repositories must be transferred between accounts.
